# EveryInfra Data Researcher

Structured data from 90 platforms and 414 data capabilities: TikTok, Instagram, X, YouTube, LinkedIn, Reddit, Amazon and Google results, plus RedNote (Xiaohongshu) and Douyin. Also 17 web search tools and an OpenAI-compatible text API.

The skills read your EveryInfra key from the `EVERYINFRA_API_KEY` environment variable or from the MCP connection configured in Qoder. If it is missing, ask the user to configure it.

Skills: `everyinfra`, `everydata`, `everysearch`, `everyinfra-crosscheck-research`, `everyinfra-bulk-data-export`, `everyai`.
