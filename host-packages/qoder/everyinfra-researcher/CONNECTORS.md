# Connector dependency

This kit uses one remote MCP server, not an OAuth connector from the marketplace.

| Server | Address | Transport | Auth | Key |
|---|---|---|---|---|
| everyinfra | https://api.everyinfra.com/mcp | Streamable HTTP | `Authorization: Bearer` plus an API key | Create one at https://everyinfra.com/en/docs?utm_source=qoder&utm_medium=directory&utm_campaign=listing_2026q4&utm_content=connectors#quickstart |

Tool discovery needs no key. Paid calls need the key. Pricing starts at $0.56 per 1,000 data calls; failed or empty calls are not charged.
